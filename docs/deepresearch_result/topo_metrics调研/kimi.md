

# 拓扑结构评估指标与拓扑保持损失函数：开源Python工具库设计调研

## 1. 核心指标体系总览

### 1.1 拓扑感知评估指标（Topology-aware Evaluation Metrics）

#### 1.1.1 遥感道路提取与道路图重建指标

遥感道路提取领域经过多年发展，已形成一套相对成熟的拓扑评估指标体系。这些指标的核心挑战在于：**道路网络本质上是一个图结构，传统的像素级评估指标（如IoU、F1-score）无法有效捕捉连通性错误**——一条道路的中断可能导致两个区域完全断开，这在导航应用中是不可接受的灾难性错误，但在像素级指标中仅表现为少量像素的误分类。

**APLS（Average Path Length Similarity）** 是SpaceNet挑战赛引入的核心指标，现已成为道路图评估的事实标准。该指标通过比较地面真实图与预测图中对应顶点对之间的最短路径长度来量化拓扑相似性。具体而言，对于地面真实图中随机采样的顶点对(v₁, v₂)，首先在预测图中找到其对应顶点(v̂₁, v̂₂)，然后计算两组最短路径距离的相对误差：e(v₁,v₂) = min(1, |d_pred(v̂₁,v̂₂) - d_gt(v₁,v₂)| / d_gt(v₁,v₂))，最终APLS = 1 - (1/M)Σe(v₁,v₂)，其中M为采样顶点对数量。APLS取值范围为[0,1]，值越高表明道路网络的拓扑保持越好。该指标对路径质量极为敏感，能够检测出局部断裂导致的绕行或捷径错误，在SAM-Road、SAM-Road++、Sat2Graph等最新工作中被广泛采用。

**TOPO / TOPO-F1** 指标则侧重于局部图结构的相似性评估。其核心机制是：在地面真实图和预测图上随机采样种子顶点，从每个种子出发提取距离阈值（通常为300米）内的可达子图，然后比较这些子图在顶点和边层面的精度、召回率和F1分数。TOPO的独特优势在于能够惩罚细节拓扑错误，如错误的断开连接，但对几何精度要求严格。**不同研究组对TOPO的实现存在差异**——Sat2Graph采用了较为严格的实现方式，能够更细致地惩罚拓扑错误。在SAM-Road的评估中，TOPO precision达到了90.47%（City-scale）和93.03%（SpaceNet），显示出该指标对精确拓扑重建的区分能力。

**Graph IoU** 是图结构上的交并比扩展，通过将预测图与地面真实图进行空间匹配后计算重叠比例。与像素IoU不同，Graph IoU需要在图节点和边层面进行匹配，通常基于距离阈值确定对应关系。

**图编辑距离（Graph Edit Distance, GED）** 衡量将预测图转换为地面真实图所需的最少编辑操作（节点插入、删除、替换，边的插入、删除）的代价总和。GED提供了最精细的图相似度度量，但计算复杂度为NP-hard，限制了其在大规模评估中的应用。

**连通性指标** 在道路网络评估中占据重要地位。除APLS和TOPO外，还包括：道路网络完整性（completeness，即召回率）、正确性（correctness，即精度）、质量（quality，F1的变体）等传统度量；以及基于节点匹配的指标，如交叉点（junction）匹配率和端点（endpoint）匹配率。RoadTracer提出的交叉点指标专门评估度≥3的节点的检测准确性，而CityScale等数据集的工作则综合了多种连通性度量。

**基于中心线的指标** 将道路表示为中心线（centerline）而非区域，通过比较中心线的几何和拓扑属性进行评估。这类指标需要先对分割掩码进行骨架化（skeletonization）或直接从矢量数据提取中心线，然后计算中心线层面的精度、召回率和几何偏差。

| 指标名称 | 核心思想 | 输入形式 | 主要优势 | 主要局限 | 典型数据集 |
|---------|---------|---------|---------|---------|-----------|
| APLS | 最短路径长度相似性 | 节点-边图 | 全局连通性敏感 | 计算开销大，需图匹配 | SpaceNet, CityScale |
| TOPO-F1 | 局部子图相似性 | 节点-边图 | 局部拓扑细节敏感 | 采样随机性，实现不统一 | SpaceNet, CityScale |
| Graph IoU | 图结构交并比 | 节点-边图 | 直观易懂 | 对连通性错误不敏感 | 通用 |
| GED | 最小编辑代价 | 节点-边图 | 理论完备 | NP-hard，不可扩展 | 小规模评估 |
| Junction Metric | 交叉点匹配 | 节点-边图 | 聚焦关键节点 | 忽略边质量 | RoadTracer |
| Centerline-based | 中心线几何拓扑 | 中心线/骨架 | 几何精度高 | 依赖骨架化质量 | Massachusetts Roads |

#### 1.1.2 医学图像分割指标

医学图像分割中的拓扑评估面临独特挑战：**血管、气道、神经元等结构具有复杂的树状或网络状拓扑，微小的分割错误可能导致临床显著的拓扑变异**（如血管断裂导致灌注区域缺失，气道断裂导致肺段功能评估错误）。

**clDice（centerline Dice）** 是医学拓扑评估的里程碑式指标，由Clough等人提出，专门用于评估管状结构的分割质量。传统Dice系数仅衡量体积重叠，而clDice通过比较预测分割和地面真实分割的骨架（中心线）来计算拓扑保持度。具体计算流程为：首先对预测掩码和真实掩码分别进行拓扑保持的骨架提取，然后计算骨架层面的Dice系数。clDice的取值范围为[0,1]，能够有效检测传统Dice无法发现的断裂错误——即使两个掩码的体积重叠很高，若骨架不连通，clDice也会显著降低。在DRIVE视网膜血管分割、TopCoW脑血管分割等任务中，clDice已成为标准评估指标。

**Betti数误差** 从代数拓扑角度量化分割的拓扑准确性。Betti数β₀表示连通分量数，β₁表示环/孔洞数（二维）或隧道数（三维），β₂表示空腔数。Betti数误差计算预测分割与真实分割的Betti数差异：|β_i^pred - β_i^gt|。该指标提供了拓扑特征的精确计数，但对Betti数相同但空间分布不同的错误不敏感。在最新研究中，Betti数误差被用于评估CREMI神经元分割、ISBI13血管分割等任务，平均Betti误差已成为拓扑性能的关键指标。

**Betti匹配误差（Betti Matching Error, BM）** 是Betti数误差的精细化扩展，被认为是"最准确的拓扑忠实分割指标"。与简单计数不同，Betti匹配通过持续同调（persistent homology）将预测和真实的拓扑特征进行空间匹配，只惩罚未能正确对应的拓扑特征。这种方法能够区分"正确的拓扑特征在错误位置"和"完全缺失的拓扑特征"，提供更精细的误差分析。在多类分割任务中，Betti匹配误差被证明比单纯的Betti数误差更能反映实际拓扑质量。

**骨架精度/召回率（Skeleton Precision/Recall）** 是clDice概念的进一步扩展，将骨架层面的评估分解为精度和召回率两个维度。骨架精度衡量预测骨架中属于真实骨架的比例，骨架召回率衡量真实骨架被预测骨架覆盖的比例。这种分解有助于分析分割是倾向于过度连接（高召回低精度）还是连接不足（高精度低召回）。在血管分割评估中，骨架精度/召回率与clDice结合使用，提供全面的拓扑质量视图。

**持续同调指标** 利用代数拓扑中的持续同调理论，通过追踪拓扑特征（连通分量、环、空腔）在不同尺度下的"诞生"和"死亡"，生成持续图（persistence diagram）或持续条形码（persistence barcode）。两个持续图之间的Wasserstein距离或瓶颈距离（bottleneck distance）可作为拓扑相似度度量。这种方法能够捕捉多尺度的拓扑信息，但计算复杂度较高，且需要专业的拓扑计算库（如GUDHI、Dionysus）支持。

**连通性指标** 在医学分割中有多种具体形式：包括基于连通分量分析的指标（如连通分量数误差、最大连通分量比例）、基于图论的指标（如将分割转换为图后的节点度分布、路径长度分布），以及针对特定解剖结构的专用指标（如气道树的支气管代际匹配、神经元的DIADEM评分）。

| 指标名称 | 核心思想 | 输入形式 | 拓扑敏感性 | 计算复杂度 | 典型应用 |
|---------|---------|---------|-----------|-----------|---------|
| clDice | 骨架Dice系数 | 二值掩码 | 断裂、伪连接 | 中（需骨架化） | 血管、气道分割 |
| Betti数误差 | 拓扑特征计数差 | 二值掩码 | 连通分量、环 | 中（需同调计算） | 多类分割 |
| Betti匹配误差 | 空间匹配拓扑特征 | 二值掩码 | 位置错误的拓扑 | 高（需持续同调） | 精细拓扑评估 |
| 骨架P/R | 骨架层面精度召回 | 二值掩码 | 过度/不足连接 | 中 | 血管分割 |
| 持续同调距离 | 多尺度拓扑比较 | 二值掩码 | 全局拓扑结构 | 高 | 理论分析 |
| DIADEM | 神经元树结构匹配 | 骨架图 | 分支结构 | 高 | 神经元追踪 |

#### 1.1.3 通用图结构与几何结构评估指标

通用图结构评估指标为跨领域应用提供了理论基础，其核心在于将空间嵌入的图结构进行有效比较。

**图编辑距离（GED）** 是最通用的图相似度度量，定义为将图G₁转换为图G₂所需的最少编辑操作（节点插入、删除、替换，边的插入、删除）的代价总和。GED的计算是NP-hard问题，实际应用中通常采用近似算法，如A*算法结合启发式下界、二分图匹配松弛等。在道路网络评估中，GED能够精确捕捉拓扑差异，但计算开销使其难以应用于大规模网络。

**最短路径距离误差（Shortest Path Distance Error, SPDE）** 是APLS的广义形式，适用于任意加权图。SPDE计算所有节点对之间最短路径距离的某种聚合差异（如平均绝对误差、最大误差），能够反映图的全局连通性质量。与APLS不同，SPDE不要求节点对应关系，可通过图匹配或距离矩阵比较实现。

**树编辑距离（Tree Edit Distance, TED）** 针对树结构（如有根树、有序树）的特殊情况，提供了比GED更高效的计算方案。对于气道树、血管树等具有层次结构的医学对象，TED能够利用树的层次信息实现O(n³)时间的精确计算或更快速的近似计算。

**结构精度/召回率/F1（Structural Precision/Recall/F1）** 将信息检索的概念扩展到图结构：结构精度衡量预测图中"正确"的结构元素比例，结构召回率衡量真实结构被恢复的比例。"正确性"的定义可以基于节点匹配、边匹配或子图同构，具体实现因应用而异。

**连通分量误差（Connected Component Error, CCE）** 计算预测分割与真实分割在连通分量数量、大小分布上的差异。CCE对断裂错误极为敏感——一个连通分量的分裂会导致分量数增加，而错误连接会导致分量数减少。该指标计算简单，但无法区分拓扑等价的错误（如两个分量错误连接 vs. 一个分量分裂）。

**环/孔/分支/端点/节点指标** 是针对特定拓扑特征的专用度量。例如：环数误差（cycle count error）衡量预测与真实的环结构数量差异；分支点检测率（branch point detection rate）评估树状结构的分叉点识别准确性；端点检测率（endpoint detection rate）评估终端结构的识别准确性。这些指标通常需要先将分割转换为骨架或图表示。

**Hausdorff距离在骨架/中心线上的应用** 将经典Hausdorff距离从区域边界扩展到骨架结构。有向Hausdorff距离h(A,B) = max_{a∈A} min_{b∈B} d(a,b)衡量从A到B的最大最小距离，对称Hausdorff距离为max(h(A,B), h(B,A))。在骨架上计算Hausdorff距离能够反映几何偏差，但对拓扑错误（如断裂）的敏感性不如clDice等专用指标。

**Chamfer距离在图样本上的应用** 通过将图离散化为点集（如在边上采样点），然后计算两个点集之间的Chamfer距离：d_Chamfer(P,Q) = Σ_{p∈P} min_{q∈Q} d(p,q) + Σ_{q∈Q} min_{p∈P} d(p,q)。这种方法将图比较转化为点集比较，可利用高效的最近邻搜索算法加速。

### 1.2 拓扑感知损失函数（Topology-aware Loss Functions）

#### 1.2.1 医学图像分割中的拓扑损失

拓扑感知损失函数的核心挑战在于：**拓扑特征（如连通性、Betti数）通常是离散且不可微的，而深度学习训练需要可微的损失函数**。近年来的研究通过多种数学技巧实现了拓扑损失的可微化。

**clDice损失 / soft-clDice** 是clDice指标的可微扩展。原始clDice需要不可微的骨架化操作，soft-clDice通过可微的软骨架化（soft skeletonization）近似这一过程。具体实现中，使用形态学操作的软版本（如软腐蚀、软膨胀）迭代提取概率图的"骨架"，然后计算软骨架之间的Dice损失。Mosinska等人提出的方法通过一系列最小/最大滤波器的可微近似实现软骨架化，使clDice损失能够端到端训练。在DRIVE、STARE等视网膜血管数据集上，clDice损失显著改善了血管连通性，相比标准Dice损失，clDice指标提升约5-10个百分点。

**软骨架化损失（Soft Skeletonization Loss）** 是一类更广泛的方法，不仅限于clDice。Menten等人提出的可微骨架化方法通过多项式近似形态学操作，实现了更准确的软骨架提取。这种方法可以作为通用模块，与各种基于骨架的损失（如骨架MSE、骨架交叉熵）结合使用。在MICCAI 2024的工作中，可微形态学滤波器在保持Betti数和Euler特征方面显著优于现有方法，同时计算效率更高。

**持续同调损失（Persistent Homology Loss, PH Loss）** 利用持续同调理论构建可微的拓扑损失。Clough等人的开创性工作将PH应用于分割网络的训练信号：通过计算预测分割的持续图与目标持续图之间的Wasserstein距离，并将该距离关于网络输出的梯度进行反向传播。关键创新在于利用持续同调的稳定性定理，确保梯度的有效计算。PH损失能够编码任意拓扑先验（如"左心室心肌应为一个环"），在ACDC心脏分割、胎盘分割等任务中，同时提升了Dice分数和拓扑准确性。然而，PH损失的计算开销较大，训练时间可能增加10-100倍，限制了其广泛应用。

**基于Betti数的拓扑损失** 通过直接优化Betti数误差实现拓扑保持。最新研究提出了快速计算Euler特征（χ）和Betti数的方法，利用位四元组（bit-quads）和位八元组（bit-octets）进行固定前向变换，避免了昂贵的持续同调计算。这种方法在CREMI、ISBI13、FIVES等五个数据集上实现了优于PH损失的性能，同时速度快72.7倍（0.0134s/item vs. 0.9748s/item）。该损失通过拓扑违反图（topology violation map）提供可视化的拓扑误差分析，增强了可解释性。

**拓扑保持损失（Topology-Preserving Loss）** 是一类更广泛的方法框架，包括基于同胚约束的损失、基于形变场的拓扑正则化等。Hu等人提出的通用拓扑细化方法（Universal Topology Refinement）通过后处理网络学习将任意分割输出进行拓扑优化，在保持原有分割网络架构的同时，显著降低Betti误差。

**边界/中心线/骨架损失** 通过惩罚边界或中心线的位置误差间接促进拓扑保持。例如，边界损失（Boundary Loss）计算预测边界与真实边界之间的距离加权误差；中心线损失直接回归中心线位置。cbDice损失（centerline boundary Dice）是这类方法的最新进展，通过整合边界感知和半径信息，实现了对血管直径变化的均匀适应，解决了clDice损失偏向大血管的问题。

| 损失函数 | 可微性 | 骨架化依赖 | 计算开销 | 拓扑先验灵活性 | 典型性能增益 |
|---------|--------|-----------|---------|-------------|------------|
| clDice/soft-clDice | 是（软版本） | 是 | 中 | 低（管状结构） | clDice +5-10% |
| PH Loss | 是 | 否 | 极高（~100x） | 极高（任意拓扑） | Dice +2-4%, 拓扑显著改善 |
| Fast Betti Loss | 是 | 否 | 低（~1x） | 中（Betti数约束） | Betti误差 -30-40% |
| cbDice | 是 | 是 | 中 | 中（血管专用） | Dice +1-3%, NSD +5% |
| 可微形态学损失 | 是 | 是 | 中 | 中 | Betti误差显著降低 |

#### 1.2.2 遥感道路提取中的拓扑损失

遥感道路提取的拓扑损失设计面临独特挑战：**道路网络是平面或近平面的图结构，需要保持全局连通性和正确的拓扑关系**（如交叉点、并行道路分离）。

**道路连通性损失（Road Connectivity Loss）** 直接惩罚预测分割中的连通性错误。早期方法通过设计特殊的卷积核检测断裂区域，或使用高阶势函数编码连通性约束。近年来，基于图神经网络的方法将道路分割与图结构预测联合优化，通过边预测损失促进正确的拓扑连接。

**骨架损失 / 中心线损失** 在道路提取中同样适用，但需要适应道路网络的特性（如宽度变化、交叉点复杂性）。方法包括：对分割掩码进行软骨架化后计算骨架层面的损失；直接预测中心线热力图并回归中心线位置；结合方向场预测（orientation field）损失，强制道路像素具有正确的延伸方向。

**基于路径的损失（Path-based Loss）** 是遥感领域的特色方法，直接利用路径一致性作为训练信号。这类损失通常涉及：从预测图中采样起点-终点对，计算它们之间的最短路径，然后与真实路径比较。由于最短路径计算不可微，需要特殊的松弛技巧。

**可微最短路径 / 软最短路径 / LogSumExp路径损失** 是解决路径可微性的关键技术。核心思想是用LogSumExp（也称为softmax或smooth maximum）松弛最短路径中的min操作：softmin_ε(x) = -ε log(Σ exp(-x/ε))，当ε→0时收敛于min。类似地，最短路径的动态规划递推可以松弛为可微形式。这种方法使得路径长度可以作为损失函数进行优化，在道路提取中能够直接惩罚"绕行"或"捷径"错误。然而，LogSumExp松弛的数值稳定性和计算效率仍是实际应用中的挑战，特别是当图规模较大时。

**测地距离损失（Geodesic Distance Loss）** 基于测地距离变换（geodesic distance transform）构建拓扑损失。测地距离考虑了障碍物约束，比欧氏距离更能反映拓扑结构。在道路分割中，可以计算预测分割和真实分割的测地距离场，然后比较两者的差异。这种方法对断裂敏感（断裂会导致测地距离剧增），但计算测地距离场本身需要求解偏微分方程，数值实现较为复杂。

#### 1.2.3 图学习与可微优化方法

图学习和可微优化领域为拓扑损失提供了强大的数学工具，这些方法具有广泛的适用性。

**可微最短路径（Differentiable Shortest Path）** 是一类将组合优化问题可微化的通用框架。除了LogSumExp松弛外，还包括：基于扰动的方法（perturb-and-MAP），通过向边权重添加随机扰动使argmin操作可微；隐函数微分（implicit differentiation），将最短路径作为优化问题的解进行微分；以及基于最优传输的方法，将路径比较转化为传输问题。

**可微动态规划（Differentiable Dynamic Programming）** 扩展了可微最短路径的思想，适用于更广泛的动态规划问题。通过将max/min操作替换为softmax/softmin，将argmax替换为softargmax，动态规划的递推关系变为可微。这种方法不仅适用于最短路径，还可用于序列比对、文法解析等结构化预测问题。

**Perturb-and-MAP / 可微组合优化** 提供了一种通用的随机松弛策略。核心思想是：对于组合优化问题argmax_x θ·φ(x)，通过从指数族分布采样（Gumbel分布等），期望解关于参数θ可微。这种方法的方差可能较大，需要多次采样估计梯度，但适用范围广，可用于图匹配、旅行商问题等NP-hard问题的可微近似。

**可微图匹配（Differentiable Graph Matching）** 针对图结构比较的可微需求，将图匹配问题松弛为二次分配问题（QAP）的可微近似。通过谱方法或Sinkhorn迭代实现软匹配，使得图相似度可以作为损失函数优化。这种方法在道路图提取中可用于直接优化预测图与真实图的匹配质量。

## 2. 关键指标与损失函数深度解析

### 2.1 重点指标详解

#### 2.1.1 APLS（Average Path Length Similarity）

APLS由SpaceNet挑战赛团队提出，旨在解决传统像素级指标无法评估道路网络导航质量的问题。其核心洞察是：**对于导航应用，两个位置之间的路径长度准确性比像素重叠更重要**。

**核心计算流程**包含以下步骤：（1）图构建：将道路分割掩码或矢量数据转换为节点-边图表示，节点对应道路交叉点和端点，边对应道路段；（2）节点匹配：在地面真实图G_gt和预测图G_pred之间建立节点对应关系，通常基于空间邻近性（如欧氏距离阈值）；（3）顶点对采样：从G_gt中随机采样M对顶点(v_i, v_j)；（4）最短路径计算：对每对顶点，分别在G_gt和G_pred中计算最短路径距离d_gt(v_i,v_j)和d_pred(v̂_i,v̂_j)，其中v̂_i, v̂_j是G_pred中与v_i, v_j匹配的节点；（5）误差聚合：计算归一化误差e(v_i,v_j) = min(1, |d_pred - d_gt|/d_gt)，最终APLS = 1 - (1/M)Σe(v_i,v_j)。

**开源实现状态**：SpaceNet官方提供了APLS的参考实现（Python），基于NetworkX进行图操作和最短路径计算。Sat2Graph、SAM-Road等工作也发布了各自的APLS计算代码。主要依赖包括：图处理库（NetworkX、igraph）、空间索引（R-tree、KD-tree）用于加速节点匹配。

**适用场景与局限性**：APLS特别适合评估道路网络的全局连通性和导航可用性，对以下错误敏感：道路断裂导致的绕行（d_pred >> d_gt）、错误连接导致的捷径（d_pred << d_gt）、完全断开（d_pred = ∞）。然而，APLS也存在明显局限：**对局部几何偏移不敏感**（只要路径长度不变）；**计算开销大**（需大量最短路径计算）；**节点匹配错误会传播到路径比较**；对并行道路的区分能力有限。在CityScale数据集上，由于测试集仅27张图像，APLS的可靠性受到质疑——单张图像的预测质量可能对最终指标产生显著影响。

#### 2.1.2 TOPO / TOPO-F1

TOPO指标由Bastani等人提出，旨在评估道路图的局部拓扑结构保真度。与APLS关注全局路径不同，TOPO聚焦于种子点周围的局部邻域结构。

**核心计算流程**：（1）种子点采样：在地面真实图上随机采样N个种子位置；（2）子图提取：对每个种子点，在G_gt和G_pred中分别提取距离≤R（通常R=300米）的可达子图，得到局部邻域G_gt^i和G_pred^i；（3）节点匹配：在G_gt^i和G_pred^i之间建立节点对应关系；（4）精度召回计算：将匹配的节点和边分别计算精度P_i = |matched|/|G_pred^i|，召回R_i = |matched|/|G_gt^i|；（5）全局聚合：TOPO-P = (1/N)ΣP_i，TOPO-R = (1/N)ΣR_i，TOPO-F1 = 2·P·R/(P+R)。

**实现变体与标准化问题**：**TOPO指标的一个关键问题是实现不统一**。Sat2Graph采用了"严格实现"，对细节拓扑错误惩罚较重；而其他工作可能采用更宽松的匹配阈值。这种差异使得跨研究比较变得困难。在SAM-Road++的评估中，TOPO和APLS被同时报告，两者提供了互补的信息——TOPO-F1反映局部结构精度，APLS反映全局连通性质量。

**开源实现状态**：Sat2Graph发布了TOPO的参考实现，但不同研究组的实现细节存在差异。**建立标准化的TOPO计算协议是工具库开发的重要任务**。

#### 2.1.3 clDice / soft-clDice

clDice指标填补了医学图像分割中拓扑评估的空白，特别是在管状结构分割中。

**核心计算流程**：（1）拓扑保持骨架化：对预测掩码M_pred和真实掩码M_gt分别进行骨架化，得到S_pred和S_gt。关键要求是骨架化算法必须保持拓扑（如同伦等价），即不引入或消除环、不错误合并或分裂连通分量；（2）骨架Dice计算：clDice = 2|S_pred ∩ S_gt| / (|S_pred| + |S_gt|)，其中交集基于空间邻近性定义。

**soft-clDice损失** 的实现挑战在于骨架化的不可微性。解决方案包括：（1）迭代软腐蚀/膨胀：用可微的最小/最大滤波器近似形态学操作，逐步提取"软骨架"；（2）距离变换法：利用距离场的梯度信息定位中心线；（3）神经网络近似：训练专门的网络预测骨架。Mosinska等人的方法通过一系列3×3×3的软形态学操作实现，在3D分割中取得了良好的拓扑保持效果。

**开源实现状态**：clDice的PyTorch实现可在GitHub获取（dmitrysarov/clDice），包括指标计算和损失函数实现。cbDice（centerline boundary Dice）作为改进版本，代码随论文发布。BenchmarkTopoSegMetrics项目提供了多种拓扑指标的标准化评估框架。

#### 2.1.4 基于Betti数的指标与损失

Betti数提供了拓扑特征的精确计数，是代数拓扑在图像分析中的直接应用。

**Betti数误差**：对于二值图像，β₀计算连通分量数，β₁计算孔洞数（2D）或隧道数（3D）。Betti数误差定义为各维度Betti数的绝对差之和：Betti_err = Σ|β_i^pred - β_i^gt|。快速计算方法利用位四元组（bit-quads）和位八元组（bit-octets）进行局部模式计数，通过Euler特征χ = Σ(-1)^i β_i建立联系，实现高效计算。

**Betti匹配误差**：通过持续同调将预测和真实的拓扑特征进行空间匹配。具体而言，计算两个图像的持续图D_pred和D_gt，然后寻找它们之间的最优匹配（最小化Wasserstein距离），未匹配的特征计入误差。这种方法能够区分"位置错误的正确拓扑"和"完全错误的拓扑"，提供更精细的误差分析。

**可微Euler特征/Betti损失**：最新研究通过固定前向变换（hard-coded forward transform）结合可微的后向传播，实现了Betti损失的快速计算。具体地，使用位四元组/八元组计算Euler特征，然后通过拓扑细化网络（Topology Refinement Network）进行优化。在CREMI数据集上，该方法将平均Betti误差从MedSAM的8.794降至4.941，提升43.8%。

#### 2.1.5 基于持续同调的指标与损失

持续同调（Persistent Homology, PH）是拓扑数据分析的核心工具，能够捕捉多尺度的拓扑信息。

**持续同调损失**：Clough等人的工作将PH引入深度学习损失设计。核心流程为：（1）构建滤波：对预测的概率图或二值图构建下水平集滤波（sublevel set filtration）；（2）计算持续图：追踪连通分量（0维）、环（1维）、空腔（2维）的诞生和死亡时间，得到持续图D = {(b_i, d_i)}；（3）定义损失：比较预测持续图D_pred与目标持续图D_gt的Wasserstein距离W_p(D_pred, D_gt) = (inf_γ Σ d((b_i,d_i), γ(b_i,d_i))^p)^{1/p}，其中γ为匹配。

**关键挑战**：PH损失的计算涉及复杂的代数拓扑运算，传统实现（如GUDHI库）不可微。解决方案包括：利用持续同调的稳定性定理推导梯度；使用自动微分框架（如PyTorch）封装PH计算；或采用近似方法降低计算复杂度。尽管PH损失在理论上优雅且灵活，但**其计算开销仍是主要障碍**——在3D分割中，单次前向-后向传播可能需要数秒到数分钟。

**开源实现**：topograd项目提供了MNIST实验的代码，GUDHI、Dionysus、Ripser等库提供PH计算功能，但需要额外的可微封装。

#### 2.1.6 图编辑距离（Graph Edit Distance, GED）

GED是图论中的经典NP-hard问题，定义为将一个图转换为另一个图所需的最少编辑操作（节点插入、删除、替换，边插入、删除）的代价总和。GED提供了最精细的图相似度度量，但**计算复杂度极高，限制了其在大规模评估中的应用**。

近期研究尝试通过神经网络近似GED，如GEDGNN框架通过图神经网络预测GED值和匹配矩阵，再通过后处理算法推导编辑路径，在多个数据集上将平均绝对误差降低了4.9%至74.3%。另一项工作GEDIOT则采用最优传输方法近似GED计算。

在道路网络评估中，GED能够精确捕捉节点级别的拓扑差异，如错误的交叉口合并、缺失的道路段等，但**仅适用于小规模图的精细分析**。

#### 2.1.7 骨架精度/召回率

骨架精度/召回率是clDice指标的组成部分，也可独立使用作为拓扑评估指标。该指标直接衡量预测掩码的骨架与真实掩码的拓扑一致性：骨架精度（Skeleton Precision）定义为预测骨架中位于真实骨架一定距离范围内的点比例，骨架召回率（Skeleton Recall）定义为真实骨架中被预测骨架覆盖的点比例。

与clDice相比，骨架精度/召回率更直接但不对称：精度关注预测骨架的准确性，召回率关注真实骨架的恢复程度。两者可以组合为骨架F1分数，提供平衡的评估。然而，**简单的距离阈值匹配可能产生"伪连接"问题**——预测骨架上的点虽然靠近真实骨架，但可能属于错误的拓扑分支，导致精度虚高。

#### 2.1.8 基于最短路径的图相似度

除APLS外，多种基于最短路径的图相似度度量被提出用于网络结构评估。这些方法的核心思想是通过比较图中节点对之间的最短路径长度分布或矩阵来量化图差异。例如，最短路径距离误差（Shortest Path Distance Error, SPDE）计算两个图对应节点对之间最短路径长度的平均绝对误差、最大误差等，能够反映图的全局连通性质量。

与APLS不同，SPDE不要求节点对应关系，可通过图匹配或距离矩阵比较实现。这类方法在道路网络评估中作为APLS的补充，提供更灵活的连通性分析视角。

#### 2.1.9 连通性损失

连通性损失是一类直接优化分割结果连通性的损失函数，在道路提取和医学图像分割中均有应用。在道路提取领域，连通性损失通常通过惩罚断裂的道路段和鼓励连续的道路预测来改善拓扑结构。例如，可以定义基于路径连续性的损失项，要求相邻像素之间的预测概率变化平滑，或使用高阶势函数编码连通性约束。

在医学图像分割中，连通性损失可能针对特定的解剖结构（如血管的连通树、气道的分支结构）进行设计，通过惩罚断开的端点或错误的连接来改善拓扑质量。这类损失的**可微实现通常需要特殊的松弛技巧**，如基于图拉普拉斯矩阵的谱方法或形态学操作的软近似。

#### 2.1.10 基于测地距离的拓扑指标

测地距离（Geodesic Distance）是流形上两点间最短路径的长度，在图像分析中通常通过距离变换（Distance Transform）或快速行进法（Fast Marching Method）计算。基于测地距离的拓扑指标利用预测分割与真实分割的测地距离场差异来评估拓扑质量。

测地距离损失对几何偏移具有一定的容忍性——只要测地距离结构保持，局部的几何变形不会导致指标剧烈变化；但对拓扑断裂极为敏感，因为断裂会从根本上改变测地距离场的结构。在道路提取中，测地距离损失被用于鼓励预测道路具有连续的中心线；在医学分割中，测地距离约束被用于保持血管或气道的管状形态。

#### 2.1.11 可微最短路径/软最短路径/LogSumExp softmin路径损失

这类方法是连接组合优化与深度学习的关键技术，旨在将最短路径计算嵌入神经网络的前向-反向传播流程。传统Dijkstra或Bellman-Ford算法不可微，无法直接用于端到端训练。

**LogSumExp松弛**是核心技术：对于最短路径问题min_{P∈𝒫(s,t)} Σ_{e∈P} w_e，其中𝒫(s,t)为s到t的所有路径集合，w_e为边权重。该问题的不可微性源于min操作和离散的路径选择。LogSumExp松弛将min替换为softmin：softmin_ε(w) = -ε log(Σ_{P∈𝒫} exp(-Σ_{e∈P} w_e / ε))。当ε→0时，softmin收敛于min；较大的ε提供更平滑的近似但可能引入偏差。

**动态规划松弛**：Dijkstra算法的动态规划形式d(v) = min_{u∈N(v)} [d(u) + w(u,v)]可以松弛为d_soft(v) = softmin_ε [d_soft(u) + w(u,v)]。这种松弛使得整个最短路径计算可微，但数值稳定性需要特别注意——exp操作可能导致溢出，需要log-space计算技巧。

**实际应用挑战**：在道路提取中，图规模可能达到10⁴-10⁶节点，完整的全对最短路径计算不可行。实际应用中通常采用采样策略（如随机采样100-1000对节点），或限制路径搜索区域。此外，**LogSumExp松弛的梯度可能集中在少数"最优"路径上，导致训练不稳定**。

## 3. 方法分类体系（Taxonomy）

### 3.1 基于掩码的方法（Mask-based）

基于掩码的方法直接操作像素/体素级别的二值掩码或概率图，无需显式的图或骨架表示。这类方法的优势在于实现简单、计算高效，适合作为基础评估和快速迭代；劣势在于对拓扑结构的表达能力有限，可能遗漏关键的连通性错误。

**典型指标**：传统Dice、IoU、准确率、精度、召回率；Betti数误差（通过直接分析掩码的拓扑）；连通分量误差；Euler特征误差。

**典型损失**：标准交叉熵、Dice损失、Tversky损失；边界损失（通过距离变换间接促进拓扑保持）；基于测地距离的损失。

**适用场景**：快速原型验证、大规模筛选、作为其他方法的基准对照。在工具库中，这类方法应作为基础功能优先实现。

### 3.2 基于骨架的方法（Skeleton-based）

基于骨架的方法将管状或线状结构转换为中心线表示，在保持拓扑的同时大幅降低数据维度。这类方法对断裂、伪连接等拓扑错误敏感，是医学图像分割的核心评估手段。

**典型指标**：clDice、骨架精度/召回率、中心线Hausdorff距离、DIADEM评分（神经元）、骨架Chamfer距离。

**典型损失**：clDice损失、soft-clDice、cbDice、可微形态学损失、骨架回归损失。

**关键依赖**：拓扑保持骨架化算法。传统骨架化（如Zhang-Suen、Lee-Kashyap）不可微且可能破坏拓扑；现代方法通过可微近似或专用网络实现软骨架化。**工具库需要集成多种骨架化选项，并明确标注其拓扑保证性质**。

**适用场景**：血管分割、气道分割、神经元追踪、裂缝检测、河网提取等管状/线状结构。

### 3.3 基于图的方法（Graph-based）

基于图的方法将结构显式表示为节点-边图，提供最完整的拓扑信息。这类方法能够精确评估网络连通性，但需要从分割掩码或矢量数据进行图提取，引入了额外的处理步骤和潜在误差源。

**典型指标**：APLS、TOPO-F1、Graph IoU、图编辑距离、结构精度/召回率、节点匹配率（交叉点、端点）。

**典型损失**：图匹配损失、边预测损失、节点属性回归损失、图神经网络中的拓扑正则化。

**关键依赖**：图构建算法（从掩码/矢量到图）、图匹配算法（建立预测与真实的对应）。图构建涉及骨架化、节点检测、边连接等多个步骤，每个步骤都可能引入误差。**工具库需要提供灵活的图构建管道，并支持从多种输入格式（掩码、矢量、点云）构建图**。

**适用场景**：道路网络提取、河网提取、神经元连接组、血管网络分析。

### 3.4 基于路径的方法（Path-based）

基于路径的方法通过比较节点对之间的路径特性来评估拓扑质量，是全局连通性评估的核心手段。

**典型指标**：APLS、最短路径距离误差、路径一致性指标、旅行时间相似性。

**典型损失**：可微最短路径损失、LogSumExp路径损失、测地距离损失。

**关键特征**：路径方法天然关注全局连通性，对导航和流动模拟等应用至关重要。主要挑战在于计算效率（需大量最短路径计算）和可微性（最短路径的不可微性）。

**适用场景**：道路网络评估、河网流动分析、血管灌注模拟、神经元信号传导路径。

### 3.5 基于持续同调的方法（Persistent-homology-based）

基于持续同调的方法提供了最理论完备的拓扑分析框架，能够捕捉多尺度的拓扑信息。

**典型指标**：Betti匹配误差、持续图距离（Wasserstein、瓶颈距离）、持续景观（persistence landscape）差异。

**典型损失**：PH损失、拓扑层损失（topology layer loss）。

**关键依赖**：持续同调计算库（GUDHI、Dionysus、Ripser）、自动微分框架的可微封装。PH方法的计算复杂度较高，且需要一定的拓扑学背景知识才能正确使用。

**适用场景**：需要精细拓扑控制的复杂结构、理论研究、作为其他方法的验证基准。

### 3.6 基于距离场的方法（Distance-field-based）

基于距离场的方法利用距离变换将拓扑信息编码为连续场，便于可微优化。

**典型指标**：距离场MSE、距离场相关性、归一化表面距离（NSD）。

**典型损失**：距离场回归损失、测地距离损失、边界损失。

**关键特征**：距离场提供了从二值掩码到连续表示的自然过渡，适合与深度学习框架集成。测地距离场特别能够反映拓扑约束（障碍物导致距离剧增）。

**适用场景**：作为其他拓扑损失的辅助项、快速拓扑近似评估、实时应用。

### 3.7 基于可微优化的方法（Differentiable-optimization-based）

基于可微优化的方法是一类新兴的通用技术，旨在将组合优化问题嵌入深度学习框架。

**典型方法**：可微最短路径、perturb-and-MAP、可微动态规划、隐函数微分、最优传输松弛。

**关键特征**：这些方法不针对特定应用，而是提供通用的数学工具。其核心优势在于理论保证和广泛适用性；劣势在于实现复杂度和数值稳定性挑战。

**适用场景**：需要端到端优化复杂拓扑约束的高级应用、研究新方法的原型开发。

#### 4.2.1 低难度实现

**具体方法**：传统像素级指标（Dice, IoU, 精度, 召回率, F1）；连通分量误差；Betti数误差（基于位四元组的高效算法）；基础clDice指标（调用现有骨架化库）；APLS（基于NetworkX的标准实现）。

**原因说明**：这些方法具有成熟的开源实现、明确的算法流程、有限的依赖项。例如，Betti数误差的快速算法通过局部模式查表实现，代码量不足百行；APLS的SpaceNet官方实现可直接适配。主要工作在于API设计和输入输出标准化，而非算法创新。

#### 4.2.2 中难度实现

**具体方法**：soft-clDice损失（需实现或集成可微骨架化）；TOPO-F1（实现不统一需标准化）；骨架精度/召回率（需可靠的骨架化和匹配算法）；cbDice损失（需距离变换和半径估计）；快速Betti损失（需实现拓扑细化网络）；测地距离损失（需数值求解器）。

**原因说明**：这些方法的核心算法已有文献描述，但实现细节可能影响性能。例如，soft-clDice的不同软骨架化实现会导致显著的性能差异；TOPO-F1的严格/宽松实现变体需要仔细处理。工具库需要提供灵活的参数配置，并进行充分的单元测试确保与官方实现的一致性。

#### 4.2.3 高难度实现

**具体方法**：PH损失的可微封装（需深度集成GUDHI等库与自动微分）；可微最短路径损失（数值稳定性挑战）；GED的精确计算（NP-hard，需高效近似算法）；perturb-and-MAP框架（高方差梯度估计）；Betti匹配误差（需完整的持续同调计算管线）。

**原因说明**：这些方法涉及深刻的数学理论和复杂的数值计算。PH损失的可微性需要自定义自动微分规则，或采用隐函数微分等高级技术；可微最短路径的LogSumExp松弛在大规模图上可能出现数值溢出；GED的近似算法需要在效率和精度之间仔细权衡。这些方法的实现可能需要数月的研究级开发，且需要与领域专家紧密合作验证正确性。

### 4.3 运行效率评估

#### 4.3.1 适合批量评估的方法

**具体方法**：像素级指标（Dice, IoU等）；Betti数误差（位四元组算法，O(n)像素遍历）；距离场指标（GPU加速的距离变换）；基础clDice（批量骨架化需优化）。

**性能特征**：这些方法主要涉及张量操作，可充分利用GPU并行计算。例如，Betti数误差的位四元组算法在GPU上可实现每秒处理数百张图像；距离变换有成熟的cuCIM等GPU实现。批量评估时，内存带宽而非计算能力通常是瓶颈。

#### 4.3.2 不适合大规模评估的方法

**具体方法**：精确GED计算（NP-hard，仅适用于<100节点的图）；完整PH计算（立方复杂度于单纯形数量）；精确Betti匹配（需解最优传输问题）；全对最短路径APLS（O(V³)或O(VE log V)）。

**性能瓶颈**：这些方法的计算复杂度随输入规模超线性增长。例如，在SpaceNet规模的道路网络（10⁴-10⁵节点）上，精确GED不可行；PH计算在3D医学图像中可能产生数百万单纯形，内存需求巨大。评估这些指标需要显著的计算资源投入，或采用激进的近似策略。

#### 4.3.3 需要加速的方法

**具体方法**：APLS（节点采样和近似最短路径）；TOPO-F1（并行子图提取）；PH损失（持续同调近似、降采样）；可微最短路径（稀疏图算法、区域限制）。

**加速策略建议**：（1）APLS可采用层次化方法，先粗粒度筛选关键节点对，再精细计算；（2）PH计算可采用α-shape等稀疏化技术减少单纯形数量，或使用Ripser等高效库；（3）可微最短路径可采用A*等启发式搜索限制探索区域，或使用神经近似替代精确计算；（4）通用策略包括：多线程/多进程并行、GPU卸载、缓存中间结果、增量更新等。

## 5. APLS与TOPO-F1的补充性分析

### 5.1 APLS的局限性

APLS作为道路网络评估的核心指标，存在多方面的局限性需要其他指标补充。

**对局部拓扑错误的敏感性不足**：APLS通过路径长度间接反映拓扑，对小范围的局部错误可能不敏感。例如，一个小的绕行（增加10%路径长度）在大量正常路径的统计中可能被淹没；而一个关键的局部断裂若存在替代路径，APLS可能完全无法检测。这种"平均效应"使得APLS不适合评估对局部精度要求高的应用场景。

**对几何偏移与拓扑错误的区分能力有限**：APLS主要关注路径长度的数值差异，难以区分"正确的拓扑但错误的几何位置"和"错误的拓扑但近似的路径长度"。例如，一条平行道路的误识别可能导致相似的路径长度但完全错误的拓扑结构。

**计算效率瓶颈**：APLS需要大量最短路径计算，在大型网络上成为显著瓶颈。SAM-Road++指出CityScale数据集仅27张测试图像，单张图像的预测质量可能对APLS产生显著影响，降低了指标的可靠性。SpaceNet数据集的APLS计算也需要高效的图处理基础设施支持。

### 5.2 TOPO-F1的局限性

TOPO-F1作为局部拓扑评估指标，同样存在需要补充的局限。

**采样策略带来的随机性**：TOPO-F1依赖随机种子点采样，不同采样可能导致显著差异。虽然增加采样数可降低方差，但计算成本随之增加。这种随机性使得小规模评估的结果可信度降低，需要多次重复评估或确定性采样策略。

**对全局连通性的评估能力有限**：TOPO-F1聚焦于局部邻域（通常300米半径），对超出该范围的全局连通性错误不敏感。例如，两个 distant 区域之间的连接断裂不会在任何局部邻域中体现，导致TOPO-F1完全遗漏此类错误。

**实现复杂度与标准化问题**：TOPO-F1的实现涉及多个启发式步骤（种子点选择、最近邻匹配、子图提取、IoU计算），每个步骤的参数选择都可能影响最终结果。不同研究组（Sat2Graph、SAM-Road等）的实现细节存在差异，缺乏统一标准，导致跨研究比较困难。

### 5.3 可补充的指标类别

基于上述分析，以下指标类别可以有效补充APLS/TOPO-F1的不足：

| 补充指标 | 补充能力 | 与APLS/TOPO-F1的关系 |
|---------|---------|-------------------|
| clDice | 管状结构的骨架拓扑保持 | 独立于图提取流程，对骨架断裂更敏感 |
| Betti数误差 | 全局拓扑特征计数（连通分量、环） | 提供APLS缺乏的拓扑不变量信息 |
| Betti匹配误差 | 空间定位的拓扑特征匹配 | 精细的拓扑错误定位与修正指导 |
| GED（启发式） | 细粒度的图编辑诊断 | 提供可解释的拓扑错误类型分析 |
| 测地距离指标 | 连续几何-拓扑联合评估 | 解耦几何偏移与拓扑变化 |

### 5.4 多指标联合评估策略

建议采用**分层评估框架**：第一层使用快速指标（IoU、连通分量数）进行初步筛选；第二层使用APLS+TOPO-F1进行标准评估；第三层使用clDice、Betti数误差等进行诊断性深入分析。不同应用场景可配置权重：导航应用侧重APLS，地图制图应用侧重TOPO-F1，自动驾驶安全验证则增加clDice和持续同调指标的权重。

### 6.2 指标API设计（Metric API Design）

所有指标遵循统一的调用模式：

```python
from topometry.metrics import APLS, clDice, BettiNumberError

# 统一指标接口
class TopologyMetric:
    def __init__(self, **config):
        """初始化指标，接收配置参数"""
        pass
    
    def __call__(self, pred, target, **kwargs):
        """
        计算指标值
        
        Parameters:
        -----------
        pred : np.ndarray or Graph or Skeleton
            预测结果，支持多种输入格式
        target : np.ndarray or Graph or Skeleton  
            Ground truth
        **kwargs : 额外参数（如图像分辨率、匹配阈值等）
        
        Returns:
        --------
        dict : 包含指标值和辅助信息的字典
        """
        pass
    
    def supports_input(self, input_type):
        """检查支持的输入类型"""
        pass

# 使用示例
# 方式1：直接从掩码计算（自动后处理）
apls = APLS(weight='length', control_point_spacing=5.0, graph_builder='skeleton')
score = apls(pred_mask, gt_mask, image_resolution=0.5)

# 方式2：从预提取的图计算
score = apls(pred_graph, gt_graph, input_type='graph')

scores = apls.batch_evaluate(pred_batch, target_batch, n_workers=4)
```

**关键设计原则**：输入类型自动检测与转换；惰性计算（骨架化、图构建结果缓存）；与NumPy/PyTorch张量的无缝互操作；详细的错误信息和诊断日志。

### 6.3 损失API设计（Loss API Design）

损失函数深度集成PyTorch，支持自动微分和GPU加速：

```python
import torch
import torch.nn as nn
from topometry.losses import SoftClDiceLoss, BettiMatchingLoss

# 统一损失接口
class TopologyLoss(nn.Module):
    def __init__(self, weight=1.0, **config):
        super().__init__()
        self.weight = weight
    
    def forward(self, pred, target, **kwargs):
        """
        计算损失值
        
        Parameters:
        -----------
        pred : torch.Tensor
            预测概率图 [B, C, H, W] 或 [B, C, D, H, W]
        target : torch.Tensor
            Ground truth掩码（相同形状）
        
        Returns:
        --------
        torch.Tensor : 标量损失值
        """
        pass

# soft-clDice损失
soft_cldice = SoftClDiceLoss(
    iter_=10,           # 软骨架化迭代次数
    smooth=1e-5,
    combine_with='dice', # 与Dice损失的加权组合
    alpha=0.5           # 权重系数
)

# Betti匹配损失
betti_loss = BettiMatchingLoss(
    dimensions=[0, 1],  # 优化的同调度数
    use_optimized=True, # 使用C++后端
    persistence_threshold=0.1  # 噪声过滤阈值
)

# 组合使用
combined_loss = 0.5 * dice_loss + 0.3 * soft_cldice + 0.2 * betti_loss
```

**关键考量**：梯度数值稳定性（特别是迭代池化和PH计算）；混合精度训练兼容；损失组件的独立监控和可视化；超参数的合理默认值和自动调优建议。

## 7. 实现困难与开源缺口分析

### 7.1 高引用但实现困难的指标/损失

| 方法 | 困难原因 | 当前状态 | 替代方案建议 |
|-----|---------|---------|-----------|
| Betti匹配损失 | 依赖优化的C++持续同调，编译复杂 | 有C++实现，Python绑定不完善 | 提供预编译wheel，简化安装 |
| 可微最短路径损失 | 大规模图的全可微性，内存爆炸 | 研究前沿，无成熟实现 | 先提供简化版本（小图、近似） |
| 精确GED | NP-hard，启发式设计困难 | 仅小规模可用 | 提供多种近似算法，明确适用场景 |
| 完整PH损失管线 | 可微封装复杂，数值不稳定 | 多个研究原型，无统一实现 | 分阶段实现，先评估后损失 |

### 7.2 高引用但速度慢的指标/损失

| 方法 | 性能瓶颈 | 加速策略 |
|-----|---------|---------|
| APLS（大图） | 全对最短路径O(V³) | Landmark近似、并行Floyd-Warshall |
| 原始PH计算 | 立方复形构建O(n³) | 使用BettiMatching-3D、GPU加速 |
| soft-clDice（3D） | 迭代池化内存密集 | 分块处理、混合精度、减少迭代次数 |
| TOPO-F1（密集采样） | 多次全图BFS遍历 | 并行种子点处理、子图缓存 |

### 7.3 定义不统一的指标/损失

| 方法 | 版本差异 | 标准化建议 |
|-----|---------|-----------|
| TOPO-F1 | Sat2Graph严格版 vs. SAM-Road宽松版 | 定义参数化接口，提供预设配置 |
| APLS | 控制点注入策略、双向平均方式 | 文档化所有变体，推荐默认配置 |
| 骨架精度/召回率 | 距离阈值、匹配算法选择 | 提供多种匹配策略，标注推荐设置 |
| 连通性损失 | 松弛策略多样 | 抽象基类，插件式实现 |

| 方法 | 复现难度 | 社区贡献机会 |
|-----|---------|-----------|
